Install command

PK2 selected

curl -fsSL https://erykwieliczko.github.io/omarchy-scripts/install.sh | bash -s -- --options=PK

Installs

  • KDE Plasma
  • Apple keyboard settings
View install.sh

Running it

  1. Open a terminal on your Omarchy install and paste the command.
  2. Enter your password when sudo asks for it.
  3. Reboot yourself when it finishes, if needed. The script never reboots for you.
  4. With Steam selected, sign in to Steam and install your games.
